Getting started with jmpread

This package imports common JMP table encodings using native R. Python and JMP are not runtime dependencies. Compatibility is limited to the documented encodings.

Read the bundled table

library(jmpread)
path <- system.file("extdata", "jmpreader_jl", "example1",
                    "example1.jmp", package = "jmpread")
data <- read_jmp(path)
data[, c("ints", "floats")]

##   ints floats
## 1    1   11.1
## 2    2   22.2
## 3    3   33.3
## 4    4   44.4

Choose columns

Column names and order follow the original table. select and exclude accept exact names.

read_jmp(path, select = c("floats", "ints"), metadata = FALSE)

## 1    1   11.1

Keep dates and missing values

JMP date and time displays store seconds since 1904-01-01. POSIXct preserves time of day even for date-looking values. Durations use difftime. Missing numeric values become NA; empty strings remain empty strings.

Inspect source metadata

attr(data, "jmp_metadata")$build

## [1] "Jul 23 2023, 19:09:15, Release, JMP, Version 17.2.0"

attr(data[["date"]], "jmp_metadata")$storage

## [1] "date"

Raw post-header blocks are retained, including payload bytes, so metadata can increase memory use. Notes, units, labels and formulas are not exposed as structured fields yet. Formulas are never executed. Row-state columns are lists of raw bytes.

Use your own files

Use a table you created yourself or have documented permission to use.

my_table <- read_jmp("my-data.jmp")
summary(my_table)

Help and support

Use ?read_jmp for all options and supported encodings. Report problems through the issue tracker, including your R version, package version and a small example you have permission to share.
